# Zils brand kit

Logos, colors and type for anyone writing about or building with [Zils](https://zils.ai).

## Logo

The logo is the word **Zils** set in Grenze Gotisch Semibold. Always write it as "Zils", never "ZILS" or "zils".

| File | Use on |
|---|---|
| [`zils-wordmark-purple`](logo/zils-wordmark-purple.svg) ([PNG](logo/zils-wordmark-purple.png)) | light backgrounds (main logo) |
| [`zils-wordmark-periwinkle`](logo/zils-wordmark-periwinkle.svg) ([PNG](logo/zils-wordmark-periwinkle.png)) | dark backgrounds |
| [`zils-wordmark-white`](logo/zils-wordmark-white.svg) ([PNG](logo/zils-wordmark-white.png)) | photos and colored backgrounds |
| [`zils-wordmark-black`](logo/zils-wordmark-black.svg) ([PNG](logo/zils-wordmark-black.png)) | one-color print |
| [`zils-icon`](logo/zils-icon.svg) ([PNG](logo/zils-icon.png)) | avatars, favicons, app icons |

Use the SVG files when you can. The PNGs are 2048 px wide (icon: 512 px) with transparent backgrounds.

Leave clear space around the logo at least the height of the "i" dot. Don't stretch, recolor, outline, rotate or add effects to it.

## Colors

| Name | Hex | Use |
|---|---|---|
| Zils purple | `#4b44c8` | logo on light |
| Periwinkle | `#8f88ff` | logo on dark |
| Orange | `#ff7a2f` | accents, primary buttons |
| Ink | `#0f0f13` | dark background |
| Panel | `#18191e` | dark surface |
| Paper | `#faf9fc` | light background |
| Text | `#1c1a26` | text on light |
| Mist | `#e8e6ef` | text on dark |

**Spectrum.** The brand gradient runs warm to cool:

`#ef8d5a` → `#d9a08c` → `#cfa2e4` → `#c3b4f6` → `#a9b5f2` → `#8ea6ff`

```css
background: linear-gradient(90deg, #ef8d5a, #d9a08c, #cfa2e4, #c3b4f6, #a9b5f2, #8ea6ff);
```

Use it for blocks, bars and large numbers, not as a full background.

## Type

| Role | Font |
|---|---|
| Logo only | [Grenze Gotisch](https://fonts.google.com/specimen/Grenze+Gotisch) Semibold |
| Headings and body | [Inter Tight](https://fonts.google.com/specimen/Inter+Tight) (headings Light 300, body Regular 400) |
| Labels and data | [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono), uppercase with wide tracking |

All three fonts are free on Google Fonts.
